IMX676 native RAW12 mode extension -- 2026-10-15
================================================

Scope
-----
One FRAMOS IMX676 on EDGEDES ADI v18 physical port 0 using the existing
FFA-GMSL-SER-V2A, Edge-AI Orin NX16G, NVIDIA R39.2.1 and Linux
6.18.48-yocto-standard-adi-v18. Ports 1-3 were empty. This is a generic,
uncalibrated ISP demo, not FRAMOS factory tuning or production qualification.

Implementation
--------------
OOT patch 0107 keeps all six original sensor register arrays, mode-0 write
order, BLKLEVEL 50, four-lane 720-Mb/s link and 37.125-MHz MCLK unchanged.
It adds full-frame 15 FPS and the vendor's non-binned 3552x2160 window.
The crop starts at native (0,698), preserving RGGB parity. RAW10, color
binning, HDR and faster link rates are not enabled.

Mode 0 retains HMAX 1256/VMAX 5912 and its existing exposure conversion.
The new HMAX 1320 timing is derived, not a copied vendor timing table.
It is longer than the reference 1256-clock minimum for this lane rate.
At 74.25 MHz, VMAX 3750/2250 gives exact nominal 15/25 FPS; both are even
and exceed the vendor active-height-plus-72 minimum. New exposures use
exact sensor-clock arithmetic, minimum 36us and maximum 66524/39857us.
DT line_length 4267 is the nearest integer model of the unchanged 240-MHz
CSI pixel rate; it does not alter active width or CSI pixel packing.

Checked per-device mode bounds avoid out-of-range DT indexing and do not
mutate the shared format table. Legacy single-mode DTs retain one mode.
The CSI descriptor uses selected geometry rather than fixed native size.

EDGE_AI_IMX676_EXTENDED_MODES defaults to "1" since 2026-10-16 and selects
both additional DT modes and the matching NITO. Initial 2026-10-15 testing
enabled the same flag explicitly while its original default was "0".
Setting it to "0" restores the native-only DT/NITO. IMX678's separate flag and
profiles are preserved. The original source NITOs remain byte-identical.
Runtime IMX676 filename stays edgedes-imx676-demo.nito under
/var/nvidia/nvcam/settings; the model-selection helper is unchanged.

Limitations
-----------
Only one IMX676 on port 0 was hardware-tested. Other ports, mixed models,
simultaneous high-rate streams, cold-power reliability, AE/AWB convergence
metadata, lens shading, factory color and production use remain unqualified.
30 FPS full resolution requires a faster sensor link than this preserved
720-Mb/s configuration. Cropping is sensor windowing, not full-field scaling.
