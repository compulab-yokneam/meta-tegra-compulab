Failures investigated, not counted as passes
-------------------------------------------
The first pre-package trial reached EOS without frames with a busy bypass
control/stale queue. Bounded client cleanup and daemon restart recovered it;
subsequent ioctl tracing showed controls accepted. No driver fix was made.

Stock GTK startup hit EGL_BAD_CONFIG because the realized Xwayland view's
visual differed from the selected EGL config. The gated sample patch now
matches the actual native visual; it does not add a native Wayland backend.

A patched GTK still trial initially segfaulted inside vendor libnvmm_jpeg.so,
with "lsmod: not found". Saved core placed the fault in jpeg_write_raw_data,
not GLContext. Vendor JPEG checks nvgpu through lsmod; su weston had only
/bin:/usr/bin in PATH. With process-local PATH=/usr/sbin:/usr/bin:/sbin:/bin,
JPEG and live tests passed. kmod is now an explicit demo runtime dependency.
README.md examples include that PATH without editing global system files.
