EDGEDES composable IMX676/IMX678 boot overlays -- 2026-10-13
=========================================================

Scope: Edge-AI NX16G/P3767-0000, ADI v18 and NVIDIA R39.2.1. This extends the
existing optional-link model to explicit per-port sensor choices. It does not
add sensor identification, live hotplug, synchronization or production IQ
qualification. Matching optional-link max-serdes/tegra-camera patches and
both sensor drivers remain required. The VI graph patch 0104 additionally
filters Maxim outputs/unrelated optional inputs before remote resolution and
accepts a missing remote-endpoint only on an unconfigured optional GMSL input.
Configured dangling references and ordinary graph errors remain failures.
No UEFI or NITO workaround is required for this graph-registration fix.
Patch 0105 applies the optional-input rule to media-link construction too:
absent sink references are skipped before remote parsing, independent of
endpoint order. Configured corrupt references and missing outputs remain errors.

Composition
-----------
FDT_FILE selects tegra234-edge-ai-adi-base.dtb from /boot/dtb. FDT_OVERLAYS
selects basenames from /boot/devicetree in this order:
    edgedes-adi-v18-transport-4port.dtbo
    edgedes-adi-v18-camera-imx676-portN.dtbo or
    edgedes-adi-v18-camera-imx678-portN.dtbo for each configured port N=0..3.
Select no more than one leaf per port. Transport-only is valid. Do not combine
old single-port pairs or homogeneous four-port overlays with this transport.
Leaves are independent after common transport; no future-leaf fixups exist.

Common owns stable ATR adapters/input endpoints, PHY2/CSI-C output VC0-3,
unique aliases and model-free moduleN placeholders. Each leaf adds its
serializer/sensor mode, enables moduleN and completes the GMSL graph. Empty
unconfigured endpoints are ignored; configured but absent assemblies use
optional-link discovery. Shared downstream endpoints remain available;
unused VI channels are suppressed by the driver, not by disabling PHY2.

The generator validates order, names, duplicates, base and physical ports.
Do not also set UBOOT_EXTLINUX_FDTOVERLAYS. Universal builds scope the three
configuration options to :edge-ai-shared-runtime. Detached Secure Boot
signatures are owned by the DT recipe when signing keys are configured.
Manual signed extlinux edits need re-signing. Keep a complete-DTB boot entry
without OVERLAYS for rollback. The selector clears overlay lists when
selecting a complete DTB or UEFI; it does not author modular stacks.

Argus/NITO policy
-----------------
EDGE_AI_ARGUS_NITO_SELECTION defaults to auto. Homogeneous discovered subsets
use their model-specific forced file even in marked mixed-capable profiles.
Only mixed active models select per-camera lookup, requiring the modular DT
marker. Explicit single remains homogeneous-only. Explicit per-camera retains
directory lookup for marked profiles even with one camera; legacy homogeneous
entries retain their forced-file fallback. Both condition and start check the
selected forced file is regular/readable and log the effective policy/count.

The opt-in guard allows mixed distinct ports, checks default-directory NITO
presence, unsets inherited NVCAMERA_NITO_PATH and execs the unchanged daemon.
Presence is not binary content/identity validation. Embedded badge/model
identities and native modes must match and be verified or regenerated with
official NVIDIA tools. Renaming files is insufficient. The supplied baseline
NITOs have not been qualified for automatic mixed-camera selection. No binary
patching, proprietary library replacement or NITO conversion is performed.

-----------------
The opt-in edge-ai-argus-framos-camera-menu.inc generates independent all-port
IMX676, all-port IMX678, explicit mixed and UEFI fallback entries. The default
is the homogeneous IMX676 profile. Mixed layout defaults to 676 port0 plus
678 port1, and can be changed through EDGE_AI_CAMERA_MIXED_OVERLAYS.
Label-specific FDT generation preserves kernel/initrd/APPEND and validates each
stack. 111 real-BitBake-data hook fixtures and six no-op machine/profile scope
checks passed; all 153 existing global-generation fixtures remain unchanged.
The explicit NX16G camera default is not portable to other universal modules.

ordered libfdt composition. Structural tests cover both leaf orders, symbols,
graph reciprocity, aliases, modes, module paths/status and legacy compatibility.
Guard fixtures cover opt-in/default/fallback selection and inherited overrides.
Boot-generator and complete-DTB-selector fixtures cover configuration safety.
